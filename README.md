# Data Science & Analytics at 6sense

## Overview
This project showcases my work at **6sense**, where I leveraged **machine learning and data analytics** to enhance B2B sales intelligence. The goal was to improve predictive models for customer behavior, optimize marketing insights, and refine data-driven decision-making.

## Dataset
- **Source:** Proprietary sales and marketing data.
- **Features:** Customer engagement metrics, website activity, CRM interactions.
- **Preprocessing:**
  - Cleaned and structured high-volume customer data.
  - Handled missing values and outliers.
  - Applied feature engineering for better predictive accuracy.

## Methodology
1. **Exploratory Data Analysis (EDA):**
   - Identified patterns in customer interactions.
   - Visualized trends in website engagement and campaign performance.

2. **Predictive Modeling:**
   - Developed **lead scoring models** using **Random Forest and XGBoost**.
   - Implemented **customer segmentation** via **K-Means clustering**.
   - Built **churn prediction models** to enhance retention strategies.

3. **Marketing & Sales Insights:**
   - Analyzed **attribution models** for multi-touch marketing campaigns.
   - Optimized A/B testing strategies for marketing effectiveness.
   - Provided sales teams with data-driven recommendations via **Power BI dashboards**.

## Results & Insights
- Improved lead conversion rates by **20%** through predictive modeling.
- Enhanced **churn detection accuracy** using advanced ML techniques.
- Delivered interactive **dashboard solutions** for sales & marketing teams.

## Technologies Used
- **Programming Languages:** Python, SQL
- **Libraries & Tools:** Scikit-learn, XGBoost, Pandas, NumPy, Matplotlib, Seaborn
- **Machine Learning Techniques:** Random Forest, K-Means, Logistic Regression
- **Big Data & Cloud:** AWS S3, Redshift
- **Visualization:** Power BI, Tableau

## Future Improvements
- Implement **deep learning models** for enhanced customer intent prediction.
- Develop **real-time analytics pipelines** for instant lead scoring.
- Integrate **NLP for sentiment analysis** of customer interactions.
